Yleiskuva

Model Hub siirtää Hugging Face -mallin internet-koneelta air-gapped-ympäristöön ja sieltä OpenShift AI:n PVC:lle. Mallit tallennetaan kontin sisään, ja koko kontti vietään malleineen siirtotiedostona.

  1. Vaihe 1 (internet): lataa mallit kontin sisään ja tee siirtotiedosto.
  2. Siirto: kopioi tiedostot tikulle ja air-gapped-koneelle.
  3. Vaihe 2 (air-gapped): lataa kontti, käynnistä se ja kopioi malli PVC:lle.

Vaihe 1: internet-kone (kansio model_hub)

./start.sh      # rakentaa imagen ja käynnistää kontin
# avaa http://127.0.0.1:8767, hae malli (Hae → Valitse) ja paina Lataa
./stop.sh       # valinnainen: pysäyttää kontin, mallit säilyvät
./export.sh     # tekee siirtotiedostot dist/-kansioon (--no-compress nopeuttaa)

Varoitus: älä käytä docker rm, docker run --rm tai docker compose down. Ne poistavat kontin ja sen mallit. Pysäytä aina komennolla ./stop.sh tai docker stop model-hub.

Lataus voidaan keskeyttää Keskeytä lataus -painikkeella, jolloin keskeneräiset tiedostot poistetaan. Levytila ja mallien poisto ovat oikeassa sarakkeessa.

Export-komennon voi kopioida välilehden 2. Vie OpenShift AI:hin alussa olevasta Vie air-gappediin -laatikosta.

Tee ubi9.tar internet-koneella:

docker pull registry.access.redhat.com/ubi9/ubi:latest
docker save -o ubi9.tar registry.access.redhat.com/ubi9/ubi:latest

Tikun pitää olla exFAT tai NTFS (FAT32 ei sisällä yli 4 GB:n tiedostoja). Air-gapped-koneella tarvitaan vapaata levytilaa noin kaksi kertaa arkiston koko.

Vaihe 2: air-gapped-kone

2.1 Kopioi, tarkista ja lataa

cd ~/model-hub-siirto        # kansio, johon kopioit tikun tiedostot
sha256sum -c model-hub-with-models.tar.gz.sha256   # pitää tulostaa: ...: OK
docker load -i model-hub-with-models.tar.gz
docker images | grep model-hub                      # näkyy model-hub:airgap

Windows PowerShell: (Get-FileHash model-hub-with-models.tar.gz -Algorithm SHA256).Hash.ToLower() ja vertaa tulosta .sha256-tiedostoon. Jos summa ei täsmää, kopioi tiedosto uudelleen.

2.2 Tuo apupodin image klusteriin

Kun malli kopioidaan PVC:lle, klusteriin käynnistyy hetkeksi apupodi, joka tarvitsee imagen, jossa on tar. Air-gapped-klusteri ei voi hakea sitä internetistä, joten image pitää olla klusterin omassa rekisterissä. <oma-rekisteri> tarkoittaa sitä rekisteriä, josta klusteri hakee imaget.

Tarkista ensin, onko sopiva image jo klusterissa:

oc run tartest --rm -it --restart=Never --image=<image> -- tar --version

Jos ei ole, tuo ubi9.tar klusterin sisäiseen rekisteriin:

docker load -i ubi9.tar
oc login ...
oc get route default-route -n openshift-image-registry     # <reitti>
docker login -u $(oc whoami) -p $(oc whoami -t) <reitti>
docker tag  registry.access.redhat.com/ubi9/ubi:latest <reitti>/<projekti>/ubi9:latest
docker push <reitti>/<projekti>/ubi9:latest

Jos reittiä ei ole, ylläpito avaa sen: oc patch configs.imageregistry.operator.openshift.io/cluster --type merge -p '{"spec":{"defaultRoute":true}}'

<projekti> on OpenShift-projekti, johon malli kopioidaan. Podin käyttämä osoite on:

image-registry.openshift-image-registry.svc:5000/<projekti>/ubi9:latest

Jos yrityksellä on oma rekisteri (Quay, Harbor, Artifactory), käytä sen osoitetta ja kysy se ylläpidolta. Jos image on eri projektissa kuin kohde, anna kohdeprojektille lupa: oc policy add-role-to-group system:image-puller system:serviceaccounts:<kohdeprojekti> -n <imagen-projekti>

2.3 Käynnistä Model Hub

MODEL_HUB_IMAGE=model-hub:airgap \
MODEL_HUB_LOADER_IMAGE=image-registry.openshift-image-registry.svc:5000/<projekti>/ubi9:latest \
bash ./start.sh

Tai ilman skriptiä:

docker run -d --name model-hub --restart unless-stopped -p 127.0.0.1:8767:8767 \
  -e MODEL_HUB_LOADER_IMAGE=image-registry.openshift-image-registry.svc:5000/<projekti>/ubi9:latest \
  model-hub:airgap

Avaa http://127.0.0.1:8767. Sivulla lukee offline-tila, ja oikeassa sarakkeessa näkyvät kontin mallit.

2.4 Vie malli OpenShift AI:hin

  1. Avaa välilehti 2. Vie OpenShift AI:hin.
  2. Liitä konsolin Copy login command -komento ja paina Kirjaudu.
  3. Valitse malli, projekti, PVC:n nimi ja koko (koko ehdotetaan).
  4. Paina Kopioi malli PVC:lle. Tyhjennä nollaa lomakkeen ja etenemisen seuraavaa kopiointia varten.
  5. Tee deployment OpenShift AI:ssa sovelluksen näyttämien ohjeiden mukaan: Models → Deploy model, Cluster storage, vLLM-runtime.
